#  ATM Management System

##  Project Description
This is a simple ATM Management System developed using Python. It allows users to perform basic ATM operations through a menu-driven program.

##  Features
- PIN Verification
- Check Account Balance
- Withdraw Money
- Deposit Money
- Exit the Application

##  Technology Used
- Python

##  How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python atm_management.py
```

# Project Objective
The objective of this project is to practise Python programming concepts such as variables, loops, conditional statements and user input.
